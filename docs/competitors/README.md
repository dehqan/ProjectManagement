# تحلیل رقبا و ابزارهای موجود — ورودی بخش ۲ پروپوزال

**پرسش بخش ۲:** چرا ابزارهای موجودِ در دسترس تیم ایرانی کافی نیستند؟ جواب باید با شواهد باشد، نه ادعا.

هر فایل یک دسته از رقبا را پوشش می‌دهد. برای هر رقیب یک کارت با این فیلدها:

| فیلد | محتوا |
|---|---|
| جایگاه | یک جمله: خودش را چه معرفی می‌کند و برای کی |
| پوشش کاتالوگ | کدام شناسه‌های کاتالوگ ما را دارد؛ عمق: کامل / سطحی / ادعا |
| اتصال | چه چیزی به چه چیزی وصل است؛ API، Webhook، پیام‌رسان، اتوماسیون اداری، ابزار بیرونی |
| فارسی و شمسی | بومی، افزونه، یا وصله |
| استقرار و مدل عرضه | ابری، نصب سازمانی، هر دو؛ قیمت عمومی اگر هست |
| نقطهٔ قوت واقعی | چیزی که باید از آن یاد بگیریم |
| شکاف نسبت به تز ما | کجا «اتصال بین کار، سند، تصمیم، تأیید و مشتری» را ندارد |
| شواهد | خوانده‌شده / خلاصهٔ جست‌وجو / فرض |

| فایل | دسته | وضعیت |
|---|---|---|
| `work-management.md` | مدیریت کار عمومی: تسکولو، میزیتو، همتیک، بهتایم، تیم‌یار، پی‌گیر، بالونت | خالی |
| `bpm-office-automation.md` | اتوماسیون اداری و BPMS: دیدگاه چارگون، راهکاران، فرزین، فراگستر، پیوست | خالی |
| `crm-helpdesk.md` | CRM و تیکت: دیدار، پیام‌گستر، دانا، هلپیکال، میزخدمت | خالی |
| `domain-specialized.md` | CMMS و DCC: PMworks، راهکاران نت، ساینا، کهن؛ ورجاوند، آفام، داده‌تأمین، پروژان؛ نوین‌هاب | خالی |
| `foreign-selfhosted.md` | خارجی‌های در دسترس: Jira خوداستقرار، GitLab، Mattermost، Rocket.Chat، OpenProject، Nextcloud | خالی |
| `synthesis.md` | جمع‌بندی برای بخش ۲: چه چیزی در بازار هست، چه چیزی نیست | خالی |
