# نقشهٔ اسناد کارنما

**قرارداد مسیرها:** هر جا در این اسناد نام فایلی آمده (مثل `product/roadmap.md`)، مسیرش نسبت به همین پوشهٔ `docs/` است.

## هسته

| فایل | نقش |
|---|---|
| `process.md` | **فرایند محصول از قدم اول تا عرضه؛ کجای کاریم** |
| `decisions.md` | دفتر همهٔ تصمیم‌ها (A-01 به بعد) با دلیل و وضعیت |

## محصول — `product/`

| فایل | نقش |
|---|---|
| `product/product-definition.md` | تعریف محصول، پرسوناها، اصول |
| `product/proposal.md` | پروپوزال نسخهٔ ۱٫۰ — متن مرجع |
| `product/challenge-sheet.md` | گفته‌های صاحب محصول، تصمیم‌های مدیر محصول، تنش‌های باز |
| `product/scenarios.md` | هشت سناریوی گفتگومحور با آزمون پذیرش |
| `product/roadmap.md` | ترتیب ساخت (فاز ۰ تا ۳ و بعداً) |
| `product/success-metrics.md` | ستارهٔ قطبی، کیفیت، سرعت، پایلوت |
| `product/risks.md` | ریسک‌ها |
