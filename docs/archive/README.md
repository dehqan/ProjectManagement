# بایگانی

این پوشه مسیرهایی را نگه می‌دارد که کنار گذاشته شده‌اند. **برای تصمیم‌گیری دربارهٔ کارنما مرجع نیستند**؛ فقط به‌عنوان پژوهش پشتیبان خوانده می‌شوند.

## `integrated-platform/` — بستر یکپارچهٔ کار

پروپوزال اول: یک بستر واحد برای کار همهٔ واحدهای سازمان (پیام‌رسان، پرونده و روال، سند، پشتیبانی و …). با تصمیم A-21 (۱۴۰۵/۰۷/۰۶) کنار گذاشته شد و محصول به «کارنما، مدیریت تسک AI-first» تغییر کرد.

| مسیر | محتوا | هنوز به کار می‌آید برای |
|---|---|---|
| `proposal.md`، `proposal-draft.md`، `plan.md`، `challenge-sheet.md` | پروپوزال و برنامهٔ آن مسیر | تاریخچه |
| `decisions.md` | تصمیم‌های D- | فقط آنچه در `docs/decisions.md` به ارث رسیده معتبر است |
| `catalog.md`، `scope-proposal.md` | کاتالوگ اولیه و دامنه | تاریخچه |
| `teams/` | کارت شش تیم نمونه و جمع‌بندی | شناخت کاربر |
| `competitors/` | رقبای ایرانی و خارجی | پژوهش بازار |
| `research/` | زیرساخت داخل ایران، پیام‌رسان‌ها | زیرساخت و محدودیت‌های ایران |
| `components/`، `component-evaluation.md` | ارزیابی مؤلفه‌های متن‌باز | طراحی فنی |
| `product/` | مدل داده، معماری پیام‌رسان و … | تاریخچه |

مسیرهای داخل این اسناد به همان شکل اصلی‌شان بازنویسی شده‌اند تا به محل تازه اشاره کنند.
