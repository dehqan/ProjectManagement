# ریسک‌ها — نسخهٔ ۱٫۰

**وضعیت:** تفویضی. شدت: **ب** بالا، **م** متوسط، **پ** پایین.

## الف. وابستگی به API

| # | ریسک | شدت | کاهش |
|---|---|---|---|
| R1 | **در دسترس بودن API برای محصولی که در ایران ارائه می‌شود.** ایران در فهرست مناطق پشتیبانی‌شدهٔ Anthropic نیست. بدون حل این، مزیت اصلی محصول وجود ندارد. | ب | پیش‌شرط A-18: پیش از فاز ۰ روشن شود. معماری مستقل از مدل (A-17) تا در صورت لزوم ارائه‌دهندهٔ دیگری جایگزین شود؛ ولی کیفیت محصول بر فرض Claude طراحی شده است. |
| R2 | **قطع اینترنت بین‌الملل.** از خرداد ۱۴۰۴ تا خرداد ۱۴۰۵ حدود ۱۲۰ روز، یعنی یک‌سوم سال، ارتباط بین‌الملل قطع بود. | ب | چهار سطح تنزل با مدل محلی از روز اول (A-19)؛ پیام روشن به کاربر. باید پذیرفت که در قطع، مزیت اصلی محصول به فرمان‌های ساده محدود می‌شود. |
| R3 | تأخیر شبکه از ایران تا API (پینگ حدود ۱۳۰ تا ۱۶۰ میلی‌ثانیه) به‌علاوهٔ فکر مدل و دورهای ابزار، که لذت تجربه را کم می‌کند. | ب | کارت پژواک محلی (A-20)؛ کش پیشوند؛ پاسخ جریانی؛ تلاش کم برای فرمان ساده؛ اندازه‌گیری از داخل ایران در فاز ۰. |
| R4 | تغییر مدل یا رفتار API در طول زمان. | م | محک‌های فاز ۰ در هر تغییر اجرا می‌شوند؛ نسخهٔ مدل صریح پین می‌شود. |

## ب. کیفیت و اعتماد

| # | ریسک | شدت | کاهش |
|---|---|---|---|
| R5 | **یک ویرایش اشتباه و بی‌صدا اعتماد را از بین می‌برد.** | ب | قاعدهٔ عمل، پیش‌نمایش، برگرداندن (A-05)؛ سیاست پیش‌نمایش از برچسب ریسک فرمان، نه تصمیم مدل؛ «صفر عمل اشتباه بی‌صدا» به‌عنوان معیار. |
| R6 | کاربر در عمل رابط دستی را ترجیح دهد و ستارهٔ قطبی بالا نرود. | ب | پایلوت فاز ۱ دقیقاً برای آزمودن همین است؛ اگر زیر ۴۰٪ ماند، بررسی می‌شود کدام محور (سرعت، دقت، اعتماد، فارسی) مقصر است. |
| R6b | **ادعای موفقیت بدون انجام کار** (شکایت اصلی از Rovo) یا ساخت تکراری (Notion). | ب | رسید فقط از نتیجهٔ واقعی لایهٔ عمل ساخته می‌شود، نه از متن مدل؛ تکراری‌یابی پیش از ساخت (AI-13). |
| R7 | **خطای بی‌صدای آرگومان فارسی:** تابع درست ولی مقدار غلط (نام، تاریخ، عدد). شواهد موجود: فراخوانی کامل درست فقط ۴۵٪. | ب | آرگومان شناسه‌محور؛ ابزار یافتن عضو و تسک؛ حل‌کنندهٔ قطعی تاریخ؛ رسید صادق که مقدارها را نشان می‌دهد؛ محک دقت آرگومان. |
| R7b | ناپایداری کار چندمرحله‌ای و چندنوبتی (افت حدود ۳۹٪ در شواهد گفتگوی چندنوبتی). | م | برنامهٔ چندمرحله‌ای همیشه پیش‌نمایش دارد؛ شاخهٔ چندنوبتی در محک. |
| R8 | کیفیت تبدیل گفتار فارسی: بهترین مدل متن‌باز حدود ۳۴٪ خطای واژه روی گفتار محاوره؛ خطای صدا و خطای فهم روی هم جمع می‌شوند. | ب | تنظیم روی دادهٔ خودمان؛ سوگیری با نام‌های فضای کاری؛ **متن همیشه پیش از اجرا دیده می‌شود**؛ معیار «موفقیت فرمان پس از تبدیل گفتار» در محک. |
