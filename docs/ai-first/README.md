# شاخهٔ اکتشافی: مدیریت تسک هوش‌مصنوعی‌محور

این پوشه یک جهت متفاوت از پروپوزال اصلی را تا انتهای پروپوزال جلو می‌برد: **مدیریت تسک بسیار باکیفیت + همکار هوشمندی که همهٔ کارها را از چت انجام می‌دهد.** پروپوزال اصلی و پژوهش‌های پشتیبانش در بقیهٔ پوشهٔ `docs/` بدون تغییر مانده‌اند و این‌جا فقط به‌عنوان مرجع استفاده می‌شوند.

| `mockup/index.html` | نمونهٔ بصری تعاملی رابط |
