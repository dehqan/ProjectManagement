# ستون ۱ — هستهٔ مدیریت تسک

**وضعیت:** نسخهٔ ۱٫۰، تفویضی. شناسه‌ها با **T-** شروع می‌شوند. ستون «هوش مصنوعی» نشان می‌دهد هر قابلیت با کدام قابلیت‌های هوش مصنوعی (`ai-experience.md`، شناسهٔ AI-) کار می‌کند؛ طبق A-04 همه‌چیز باید با هوش مصنوعی هم ممکن باشد.

## ۱. معیار کیفیت

هستهٔ دستی باید بدون هوش مصنوعی هم دلیل کافی برای خرید باشد. معیارها:

| معیار | هدف |
|---|---|
| سرعت تعامل | هر کلیک یا تایپ کمتر از ۱۰۰ میلی‌ثانیه بازخورد؛ به‌روزرسانی خوش‌بینانه در رابط |
| راست‌به‌چپ | بی‌نقص در همهٔ نماها، ویرایشگر، نمودار و موبایل؛ متن ترکیبی فارسی و انگلیسی درست |
| تقویم | شمسی بومی در انتخابگر، نماها، گزارش‌ها و تکرار؛ تعطیلات رسمی ایران؛ میلادی به انتخاب کاربر |
| کیبورد | همهٔ عمل‌ها با میان‌بر؛ نوار فرمان (Ctrl+K) |
| موبایل | اپ اندروید و iOS با همهٔ عمل‌های اصلی؛ اعلان از مسیر داخلی |
| بارگذاری | پروژهٔ ده‌هزار تسکی بدون کندی |
