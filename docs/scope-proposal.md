# پیشنهاد دامنه: اعمال قاعدهٔ D-13 روی کاتالوگ

**وضعیت:** پیشنهاد مدیر محصول، منتظر تصمیم صاحب محصول. هر ردیفی که این‌جا نیامده، به‌صورت پیش‌فرض **داخل** دامنه می‌ماند.

قاعده (D-13): داخل اگر نیاز اصلی و تکراری تیم‌های نمونه باشد؛ بیرون اگر خودش یک محصول مستقل و بزرگ باشد که سازمان به‌هرحال جدا تهیه می‌کند. برای ردیف بیرون، «اتصال» یعنی گرفتن شماره، وضعیت و نتیجه از سامانهٔ بیرونی و نمایش آن روی کار مرتبط.

حالت‌ها:
- **بیرون** — از دامنهٔ ساخت خارج؛ شناسه حفظ می‌شود با وضعیت «کنارگذاشته‌شده».
- **جزئی** — بخش «کار، درخواست، تأیید و پیگیری» می‌ماند؛ بخش «موتور تخصصی» بیرون می‌رود.
- **بسته‌بندی** — داخل دامنه، ولی با مؤلفهٔ متن‌باز بسته‌بندی‌شده طبق D-14.
- **بحث لازم** — قاعده جواب روشن نمی‌دهد؛ باید با هم تصمیم بگیریم.
