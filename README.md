# کارنما

**کارنما** یک ابزار مدیریت تسک باکیفیت و AI-first برای تیم‌های ایرانی است، در کلاس Jira، Linear و تسکولو: همهٔ قابلیت‌های مدیریت تسک بدون کم و کسری، به‌علاوهٔ همکار هوشمندی که هر کاری را از چت انجام می‌دهد و هر کاری را هم می‌شود دستی کرد.

**وضعیت:** هنوز کدی نیست. مراحل کشف، پروپوزال و نیازمندی‌ها انجام شده است؛ قدم بعد طراحی تجربه و رابط است. جزئیات در [`docs/process.md`](docs/process.md).
