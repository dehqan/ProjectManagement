# ProjectManagement — کارنما

**محصول:** کارنما، یک ابزار مدیریت تسک باکیفیت و AI-first در کلاس Jira، Linear و تسکولو برای تیم‌های ایرانی (تصمیم A-21). هنوز کدی وجود ندارد؛ مرحلهٔ فعلی پروپوزال و مشخصات محصول است.

**از اینجا شروع کنید:** `docs/ai-first/` — پروپوزال (`proposal.md`، نسخهٔ PDF در `deliverables/`)، برگهٔ چالش، تصمیم‌ها و طراحی.

## بایگانی: پروپوزال بستر یکپارچه

اسناد زیر مسیر قبلی (بستر یکپارچهٔ کار برای همهٔ واحدهای سازمان) هستند. آن مسیر کنار گذاشته شد، ولی پژوهش‌هایش (تیم‌های نمونه، رقبای ایرانی، زیرساخت داخل ایران، پیام‌رسان‌ها، کارت‌های ارزیابی مؤلفه) مرجع معتبر برای کارنما می‌مانند.

| فایل | نقش |
|---|---|
| `docs/proposal.md` | **پروپوزال نسخهٔ ۱٫۰** — نقطهٔ شروع خواندن. |
| `docs/challenge-sheet.md` | برگهٔ چالش: گفته‌های صاحب محصول، تصمیم‌های تفویضی، تنش‌های باز. |
| `docs/plan.md` | برنامهٔ اقدام تا پروپوزال: گام‌ها، وضعیت، سه قدم بعدی. |
| `docs/catalog.md` | کاتالوگ مرجع قابلیت‌ها (نسخهٔ ۰٫۵). منجمد؛ فقط اصلاح غلط. |
| `docs/decisions.md` | دفتر تصمیم‌ها با شناسهٔ ثابت، تاریخ، دلیل و وضعیت. سؤال‌های باز هم این‌جاست. |
| `docs/scope-proposal.md` | اعمال قاعدهٔ دامنه روی کاتالوگ: بیرون، جزئی، بسته‌بندی، بحث لازم. |
| `docs/proposal-draft.md` | پیش‌نویس پروپوزال در هفت بخش؛ بخش‌بخش پر می‌شود. |
| `docs/teams/` | کارت هر تیم نمونهٔ طراحی (T1 تا T6) طبق قالب D-24، و `synthesis.md` جمع‌بندی تطبیقی. |
| `docs/product/` | طراحی محصول: مدل داده، معماری پیام‌رسان، سناریوها، ترتیب ساخت، سنجش موفقیت، الزامات و ریسک. |
| `docs/research/` | پژوهش‌های پشتیبان: پیام‌رسان‌ها، زیرساخت. |
| `docs/components/` | کارت ارزیابی هر مؤلفهٔ بسته‌بندی. |
| `docs/competitors/` | تحلیل رقبا و ابزارهای موجود، ورودی بخش ۲ پروپوزال. |
| `docs/component-evaluation.md` | کارت ارزیابی هر مؤلفهٔ متن‌باز کاندید بسته‌بندی، طبق چک‌لیست D-17. |
